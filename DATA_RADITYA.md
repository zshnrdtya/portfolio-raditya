## 5. Keahlian Teknis & Ekosistem Alat (Tech Stack)

### A. Bahasa Pemrograman
- **TypeScript:** Pengetikan statis ketat, generic types, API contract integrity.
- **JavaScript (ES6+):** Async/await, DOM manipulation, functional programming.
- **PHP (8.x):** Backend modern dengan ekosistem Laravel.
- **Kotlin:** Pengembangan aplikasi Android modern.
- **Java:** Pemrograman berorientasi objek (OOP) dasar dan Android.
- **HTML5 & CSS3:** Semantik modern, aksesibilitas WCAG, Flexbox, CSS Grid.

### B. Frontend & Desain Antarmuka
- **Framework:** Next.js (App Router, Turbopack, Server Actions, SSR/SSG), React 19 / 18.
- **Styling:** Tailwind CSS (v4 & v3), Neumorphic Design System, Dark Mode Systems.
- **Animasi & 3D:** Framer Motion, Three.js, AOS (Animate On Scroll).
- **Tipografi Unggulan:** Space Grotesk (`--font-sans`), Space Mono (`--font-mono`), Poppins, Inter.

### C. Backend, Database & Arsitektur
- **Runtime:** Node.js, Next.js Server Runtime.
- **Framework Backend:** Laravel, Next.js API Routes.
- **Database:** PostgreSQL (Supabase), MySQL.
- **ORM & Query:** Prisma ORM (v7 dengan driver adapter), Raw SQL.
- **Autentikasi & Keamanan:** NextAuth.js (v5 Beta), OAuth GitHub, WebAuthn / Passkeys (Apple Face ID & Windows Hello FIDO2), JWT session tokens.
- **Real-time Telemetri:** Server-Sent Events (SSE HTTP Streaming).
- **Email Service:** Resend API.

### D. Kecerdasan Buatan (AI)
- **Model:** Google Gemini AI SDK (`gemini-2.5-flash`).
- **Implementasi:** Asisten percakapan cerdas Zeera AI, deskripsi proyek otomatis, klasifikasi intent pesan kontak.

### E. Alat Pengembangan & Desain
- **Version Control:** Git, GitHub.
- **Editor & IDE:** Visual Studio Code, Android Studio.
- **API Testing:** Postman.
- **Desain Grafis:** Figma, Canva, Blender (3D Modelling).
- **Deployment & Cloud:** Vercel, Supabase Cloud, Supabase Pooler.
- **Local Server:** Laragon.
