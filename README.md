## 📖 Tentang Proyek

Website portofolio interaktif modern yang dibangun oleh **Raditya Rai Zeeshan** (siswa Software and Game Development / PPLG di SMKN 1 Depok). Mengusung estetika visual **Neumorphism (Soft UI)** dengan palet warna lembut *Soft Mint / Sage Green* (`#C6E0D2`) dipadukan dengan aksen *Bold Emerald* (`#178358`).

Portofolio ini bukan sekadar landing page statis, melainkan aplikasi web full-stack modern yang terhubung ke database PostgreSQL, dilengkapi sistem otentikasi buku tamu, moderasi dashboard admin, formulir kontak terintegrasi, dan animasi interaktif berbasis fisika 3D.

## ✨ Fitur-Fitur Utama

### 1. ⚡ Splash Screen Animatif
- Tampilan pembuka animasi squircle logo **RRZ** yang berdenyut halus.
- Kutipan filosofi hidup: *"It's not the problem that is flawed; fix the mindset, and the problem solves itself."*
- Bar progres animasi mulus sebelum membuka halaman utama.

### 2. 🎯 Hero Section Interaktif & Integrasi Zeera AI (Mobile Mockup Layout)
- Animasi ketik otomatis (*typewriter effect*) untuk beragam peran: Fullstack Developer, UI/UX Designer, Founder of Z - Project.
- Tombol **Hire Me** (navigasi langsung ke form kontak) & **Download CV** (dokumen PDF resmi).
- Tombol **Try Zeera AI**: Membuka popup modal interaktif cerdas [Zeera AI](https://zeeraai.radityarz.my.id/) langsung di dalam website tanpa meninggalkan halaman:
  - **Mobile Mockup Display**: Rasio aspek smartphone (375px) yang melayang di tengah desktop dengan sudut melengkung mirip bezel HP dan bayangan melayang tegas.
  - **Viewport Isolation**: Tampilan antarmuka Zeera AI di dalam popup otomatis merespons sebagai antarmuka mobile murni tanpa terpotong.
  - **Window Controls Lengkap**:
    - **Minimize (`Minus`)**: Mengecilkan popup menjadi *floating pill* di sudut kanan bawah tanpa memutus atau me-reload sesi obrolan yang sedang berjalan.
    - **Maximize / Restore (`Maximize2` / `Minimize2`)**: Kemudahan beralih antara tampilan HP (375px) dan tampilan Desktop lebar secara mulus.
    - **Open in New Tab & Close**: Akses langsung ke tab baru browser serta penutupan cepat (termasuk tombol keyboard `Escape`).

### 3. 📊 Statistik Real-Time (Animated Counter)
- Angka counter dinamis dengan *Intersection Observer* (otomatis menghitung saat discroll ke layar):

- **Fitur Spesial Identity Display**: Dua kartu ID Card / Nametag fisik dengan tali lanyard (Al-Hidayah & Indi Technology) yang dapat ditarik (*draggable*) secara bebas menggunakan simulasi pegas elastis dan fisika realistis bertenaga **Framer Motion**.

- Dilengkapi modal lightbox layar penuh dengan tombol navigasi dan zoom.

### 9. 👤 About Me & Riwayat Pendidikan
- Narasi biografi mendalam, visi hidup, serta foto profil Neumorphic beraksen grayscale-to-color saat dihover.
- Timeline pendidikan lengkap (SMKN 1 Depok PPLG, MTs Alhidayah Sukatani, SDN Sukatani 7).

### 10. 📸 Photo Gallery & Client Testimonials Marquee
- Galeri foto dokumentasi kegiatan dengan tata letak marquee otomatis.
- Slider testimoni klien asli dari layanan *Z - Project* dan mentor industri (otomatis *pause* saat disentuh/hover).

### 11. 💬 Buku Tamu Interaktif (Guestbook)
- **Otentikasi Fleksibel**: Pengunjung dapat masuk menggunakan akun **GitHub** (via NextAuth) atau mengirim pesan secara anonim.
- **Interaksi Komunitas**: Fitur Like pesan, timestamp lokal Indonesia, dan sistem balasan (*threaded replies*).
- **Sistem Moderasi Ketat**: Pesan baru otomatis masuk ke status `PENDING` untuk mencegah spam sebelum disetujui tampil di publik.

### 12. 🛡️ Dashboard Moderasi Admin (`/dashraditya`)
- Halaman moderasi khusus untuk pemilik:
  - Melihat daftar pesan pending.
  - Filter pesan: Semua Pesan, Komentar Utama, Balasan.
  - Tombol **Approve** (menampilkan pesan ke publik) dan **Decline** (menolak & menghapus spam).

### 13. 📬 Formulir Kontak & Peta Interaktif
- Form kontak fungsional yang menyimpan pesan ke database PostgreSQL dan mengirim notifikasi email via **Resend API**.
- Peta lokasi Google Maps yang disematkan secara responsif dan tautan langsung ke chat WhatsApp.

### 14. 📱 Navigasi Responsif Ganda
- **Desktop**: Floating Neumorphic pill navbar di bagian atas dengan indikator aktif berbasis spring motion.
- **Mobile**: Ergonomic bottom navigation dock dengan ikon Lucide untuk kenyamanan navigasi satu tangan di smartphone.

## 🛠️ Tech Stack & Arsitektur

| Kategori | Teknologi | Deskripsi |
|---|---|---|
| **Core Framework** | [Next.js 16 (App Router)](https://nextjs.org/) | Server Components, Server Actions & Route Handlers |
| **Library UI** | [React 19](https://react.dev/) | React Hooks & Modern DOM Lifecycle |
| **Language** | [TypeScript](https://www.typescriptlang.org/) | Type-safe development di seluruh codebase |
| **Styling & Theme** | [Tailwind CSS v4](https://tailwindcss.com/) + Custom CSS | Sistem desain Neumorphism (Soft UI) berbasis CSS Variables |
| **Animations** | [Framer Motion](https://www.framer.com/motion/) & [AOS](https://michalsnik.github.io/aos/) | 3D physics drag, smooth layout transitions & scroll reveal |
| **Icons** | [Lucide React](https://lucide.dev/) | Icon library modern dan ringan |
| **Database** | [PostgreSQL (Supabase)](https://supabase.com/) | Relational database hosting dengan connection pooler |
| **ORM** | [Prisma ORM v7](https://www.prisma.io/) (`@prisma/adapter-pg`) | Type-safe schema, migrations, dan database client |
| **Authentication** | [NextAuth.js v5 Beta](https://authjs.dev/) | Autentikasi OAuth GitHub untuk guestbook |
| **Email Service** | [Resend](https://resend.com/) | API pengiriman email notifikasi pesan masuk |

## 📁 Struktur Direktori

```text
portfolio-website/
├── prisma/
│   └── schema.prisma              # Skema database (ContactMessage, ProjectStat, Guestbook)
├── prisma.config.ts               # Konfigurasi koneksi Prisma v7
├── public/
│   ├── cv/                        # File PDF Curriculum Vitae resmi
│   ├── foto-project/              # Tangkapan layar proyek unggulan
│   ├── foto-raditya/              # Foto profil, identitas, dan logo Z-Project
│   ├── gallery/                   # Dokumentasi galeri aktivitas
│   └── logo-asset/                # Logo SVG/PNG tech stack
├── src/
│   ├── app/
│   │   ├── api/
│   │   │   ├── admin/guestbook/   # Endpoint moderasi admin (GET pending, PATCH approve/reject)
│   │   │   ├── auth/[...nextauth] # Route handler NextAuth
│   │   │   ├── contact/           # API pengiriman pesan kontak & email
│   │   │   ├── guestbook/         # API buku tamu publik & reply
│   │   │   └── projects/stats/    # API pencatat like & view proyek
│   │   ├── dashraditya/           # Halaman Dashboard Moderasi Admin
│   │   ├── globals.css            # Variabel CSS Neumorphism, font, dan keyframes
│   │   ├── layout.tsx             # Root layout, metadata SEO, provider
│   │   └── page.tsx               # Halaman utama menggabungkan seluruh komponen section
│   ├── components/
│   │   ├── layout/                # Navbar (desktop & mobile dock), Footer
│   │   ├── providers/             # AOS Provider & Session Provider
│   │   ├── sections/              # Hero, Stats, TechSlider, Experience, IdentityDisplay,
│   │   │                          # Achievements, Projects, Design, About, Gallery,
│   │   │                          # Testimonials, Guestbook, Contact
│   │   └── ui/                    # SplashScreen, ZeeraModal
│   └── lib/
│       ├── auth.ts                # Konfigurasi NextAuth v5
│       └── prisma.ts              # Inisialisasi Prisma Client dengan pg adapter
├── package.json
└── tsconfig.json
```
